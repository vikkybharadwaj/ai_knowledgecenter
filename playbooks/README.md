# Playbooks

Step-by-step "how to do X" guides for recurring AI-product tasks. A playbook is
procedural (do this, then this) — distinct from `knowledge/` (understanding) and
`patterns/` (assets). A good playbook links to the patterns it uses.

## How to add
- One file per task: `how-to-<slug>.md`.
- Number the steps. State prerequisites up front. Link the patterns/configs it pulls in.
- Add a one-line pointer to the index below.
