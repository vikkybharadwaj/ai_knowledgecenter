How this base is built

the rules
01

Connect, don't dump

Every note carries 2–5 typed connections and a place on the spine. A note that links to nothing is a failure, not a draft — structure emerges from the edges.

02

Claude-specific

Content stays tied to the Claude/Anthropic stack unless an idea is genuinely foundational. The goal is mastery of one stack, not a generic AI wiki.

03

In my own words

Sources are distilled, never pasted — one atomic idea per note, explaining the why and the when to use, with the original always cited.

04

Datestamped

Anything with a shelf life — models, prices, previews — carries a retrieval date, because the stack moves fast and stale facts are worse than none.
