Concepts · the Claude tech stack

One model, many ways to steer it.

Hooks, skills, subagents, MCP, agent teams, dynamic workflows, agent view, worktrees, conventions, policies… it’s a lot of nouns. This is where I make sense of them — structured as two ways in: go deep on any single primitive, or go broad across the whole stack. Same material, two altitudes — start wherever your question is.

Conventions (CLAUDE.md / rules files)

Soft, persistent guidance the model reads every session.

 → hard

Policies (managed settings + permission rules)

Client-enforced governance that the model can’t override. Not the same as conventions.

 → hard

Hooks (vs “rules”)

Your code, run automatically on lifecycle events. Not the same as rules.
