How I learn

A repeatable loop I run on every new area — the same one that produced the Claude Code module.

01 · Capture

Gather widely

Fan out across the primary sources — official docs, engineering blogs, real practitioner write-ups — and pull the signal.

02 · Distill

Find the one idea

Compress to a mental model that organizes everything else. If I can’t draw it, I don’t understand it yet.

03 · Organize

Make it clickable

Turn the model into a navigable map: comparisons, decision ladders, and “when to use what” criteria.

04 · Retrieve

Practice to retain

Scenario-based drills and exam-grade questions so the knowledge is recall-ready, not just read-once.
