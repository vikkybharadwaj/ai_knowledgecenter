The nine you asked about

Deep-dive cards

Each opens a full page: definition, an analogy, the mechanism, who invokes it, when to reach for it (and when not), best practices, and setup. The hard badge means client-enforced; otherwise it’s soft, model-mediated.

→

Conventions (CLAUDE.md / rules files)

Soft, persistent guidance the model reads every session.

 → hard

Policies (managed settings + permission rules)

Client-enforced governance that the model can’t override. Not the same as conventions.

 → hard

Hooks (vs “rules”)

Your code, run automatically on lifecycle events. Not the same as rules.

 →

Skills (& what “routines” really means)

Reusable instructions/procedures loaded on demand. “Routines” isn’t a real term — it’s this.

 →

MCP (Model Context Protocol)

A protocol that gives the model new tools & data from external systems.

 →

Subagents

Delegated workers in their own context; only a summary returns.

 → experimental

Agent teams

A lead + peer sessions that share a task list and message each other.

 → preview

Dynamic workflows (+ ultracode)

Claude writes an orchestration script that runs dozens-to-hundreds of agents.

 → preview

Worktrees + Agent view

Git isolation per session, plus one dashboard to dispatch & watch many of them.
