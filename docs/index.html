The method

How I learn

A repeatable loop I run on every new area — capture, distill, connect, retrieve.

01 · Capture

Land it

Drop a doc, article, or URL into the CLI. /land distills it into one atomic note, in my own words.

02 · Distill

Find the one idea

Compress to a mental model. If I can’t state it as a single claim, I don’t understand it yet.

03 · Connect

Wire the dots

Every note gets typed links to its neighbours and a place on the spine, so the map grows into one brain.

04 · Retrieve

Practice to retain

Scenario drills and exam-grade questions so the knowledge is recall-ready, not just read-once.
